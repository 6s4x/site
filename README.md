# AERO-PULSE — NASA Space Apps Project Website

> **Official Project Submission & Interactive Presentation Platform for NASA International Space Apps Challenge**  
> Planetary Autonomous Wildfire Detection & Real-Time Smoke Plume Dispersion Forecasting powered by NASA Earth Observations.

---

## 🚀 Quick Start Guide

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```

### 5. Preview Production Build
```bash
npm run preview
```

## 🎨 Design & Aesthetic
- **Background:** Off-white / very light gray (`#F9F9FB` / `#FFFFFF`) creating a crisp presentation slide feel.
- **Headings & Primary Text:** Deep Charcoal / Almost Black (`#111111` / `#1E1E1E`).
- **Muted Text:** Slate Gray (`#6B7280` / `#4B5563`).
- **Accent:** Clean Blue (`#0052FF`).
- **Apple-Inspired UX:** Frosted glass navbar, slide cards, 7-slide deck viewer, 30s pitch player, and live simulation sandbox.

---

## 📋 Required NASA Space Apps Submission Sections
1. **High-Level Summary:** What was built, addressing the challenge, why it matters + 4 quantified benchmarks.
2. **Project Demo Link:** Interactive 7-slide presentation deck + 30-second pitch video player with English subtitles.
3. **Final Project Links:** Live prototype, GitHub code repository, and cloud API endpoints with Incognito verification.
4. **Project Details:** 5-stage architecture pipeline, societal impact, and full tech stack.
5. **Use of AI ("SI"):** Detailed synthetic intelligence disclosure and indelible visual watermarking tool.
6. **NASA Data Resources:** 5 integrated NASA assets (FIRMS, MERRA-2, GIBS, Landsat 9, EMIT) + live API payload explorer.
7. **References & Citations:** Space agencies, open source libraries, and dataset attributions.
8. **Rules Compliance:** 100% English verified, zero login / incognito tested, 7 slides max, 30 seconds max.
